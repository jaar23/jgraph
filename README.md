# JGraph - Java Web Project Analyzer

A powerful tool for analyzing Java web projects (Spring Boot, Jakarta EE) and visualizing their architecture through interactive graphs.

## Features

- **Deep Code Analysis**: Parses Java source code using JavaParser
- **Annotation Detection**: Recognizes Spring (`@RestController`, `@Service`, `@Repository`) and Jakarta EE (`@Path`, `@Stateless`) annotations
- **Endpoint Extraction**: Captures REST endpoints with HTTP methods, paths, and parameters
- **Call Graph Generation**: Tracks method calls from endpoints → services → repositories
- **Dependency Mapping**: Identifies `@Autowired`/`@Inject` dependency injections
- **Interactive Visualization**: Vue 3 frontend with vis-network for exploring architecture
- **Smart Search**: Filter graph by keywords across functions, parameters, and flows

## Quick Start

### Option 1: Using Docker (Recommended if you don't have Java)

1. **Build the analyzer with Docker:**
```bash
cd analyzer
docker run --rm -v "$(pwd)":/usr/src/app -w /usr/src/app maven:3.9-eclipse-temurin-11 mvn clean package
```

2. **Analyze a Java project:**
```bash
# Replace /path/to/your/java/project with your actual project path
docker run --rm \
  -v "$(pwd)":/analyzer \
  -v "/path/to/your/java/project":/project \
  -w /analyzer \
  maven:3.9-eclipse-temurin-11 \
  java -jar target/jgraph-analyzer-1.0.0.jar /project --output analysis.json
```

### Option 2: Using Local Java/Maven

1. **Build the analyzer:**
```bash
cd analyzer
mvn clean package
```

2. **Run the analyzer on your Java project:**
```bash
java -jar target/jgraph-analyzer-1.0.0.jar /path/to/your/java/project --output analysis.json
```

### Running the Frontend

1. **Install dependencies:**
```bash
cd frontend
npm install
```

2. **Start the dev server:**
```bash
npm run dev
```

3. **Open browser:**
Navigate to `http://localhost:5173`

4. **Upload the analysis.json** file generated by the analyzer

## CLI Options

```
Usage: jgraph <project-path> [OPTIONS]

Arguments:
  <project-path>           Path to Java project directory to analyze

Options:
  -o, --output <file>      Output JSON file path (default: analysis.json)
  -v, --verbose            Enable verbose output
  --include-tests          Include test files in analysis
  -h, --help               Show help message
  --version                Show version
```

## Frontend Features

### Interactive Graph Visualization
- **Hierarchical Layout**: Endpoints at top, services in middle, repositories at bottom
- **Color Coding**: 
  - Green = Endpoints
  - Blue = Services
  - Red = Repositories
- **Click & Drag**: Navigate the graph
- **Zoom**: Mouse wheel or buttons
- **Node Selection**: Click to view details

### Smart Search
- Search across:
  - Method names
  - Class names
  - HTTP paths
  - Parameters
  - Return types
  - Javadoc comments
  - Call chains
- **Real-time filtering**: Graph updates as you type
- **Path preservation**: Shows complete call paths matching search

### Details Panel
- Method signatures
- Parameters with annotations
- Return types
- Call chains (what this method calls)
- Callers (what calls this method)
- Javadoc documentation
- File location with line numbers

## Supported Annotations

### Spring Framework
- `@RestController`, `@Controller` - Controllers
- `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`, `@PatchMapping` - HTTP methods
- `@RequestMapping` - Generic mapping
- `@Service`, `@Component` - Services
- `@Repository` - Repositories
- `@Autowired`, `@Qualifier`, `@Value` - Dependency injection
- `@PathVariable`, `@RequestParam`, `@RequestBody` - Parameters

### Jakarta EE
- `@Path` - REST endpoints
- `@GET`, `@POST`, `@PUT`, `@DELETE` - HTTP methods
- `@Stateless`, `@Singleton`, `@ApplicationScoped` - Services
- `@Inject`, `@Resource` - Dependency injection

## Architecture

### Backend Flow
1. **File Discovery**: Recursively find all `.java` files
2. **Parsing**: Use JavaParser to build AST
3. **First Pass**: Detect annotations, extract metadata
4. **Second Pass**: Analyze method calls, build relationships
5. **Graph Construction**: Create nodes and edges
6. **JSON Export**: Serialize to JSON with Jackson

### Frontend Flow
1. **File Upload**: User selects analysis JSON
2. **Data Loading**: Parse and validate JSON
3. **State Management**: Store in Pinia
4. **Graph Rendering**: vis-network creates visualization
5. **Search**: Filter data and update graph
6. **Details**: Display selected node information

## Limitations

- **Reflection**: Cannot analyze dynamic method calls via reflection
- **Lambdas**: Limited support for complex lambda expressions
- **AOP**: Aspect-oriented programming calls not tracked
- **External Libraries**: Only analyzes project code, not dependencies
- **Generated Code**: May not handle Lombok or other code generation tools perfectly

## Troubleshooting

### "Failed to parse file"
- Ensure Java files are syntactically correct
- Check for unsupported Java version syntax

### "No endpoints found"
- Verify annotations are correctly placed
- Check if project uses supported frameworks

### Graph not rendering
- Ensure JSON file is valid
- Check browser console for errors
- Try a smaller project first

### Memory issues with large projects
- Increase JVM memory: `java -Xmx4g -jar jgraph-analyzer.jar`
- Exclude test directories
- Process modules separately
